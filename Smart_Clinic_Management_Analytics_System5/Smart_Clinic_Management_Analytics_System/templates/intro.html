Key Features

Everything a small clinic front desk needs for a demonstration.

{{ icon('dashboard', 26) }}

Live Dashboard

Total patients, today's appointments, revenue and charts, all calculated from the data files.

{{ icon('patients', 26) }}

Patient Records

Add, search, view, edit and delete patient records with validated forms and unique patient IDs.

{{ icon('calendar', 26) }}

Appointment Booking

Book, update and cancel visits. Duplicate doctor and time-slot bookings are blocked.

{{ icon('billing', 26) }}

Smart Billing

Totals are calculated automatically. Mark any bill as paid or unpaid with one click.

{{ icon('analytics', 26) }}

Health-Data Analytics

Seven charts built from real records: visits, revenue, paid vs unpaid, and more.

{{ icon('lock', 26) }}

Access Control

Sign-in required. Staff can work with records; only the admin can delete them.

How It Works

Built with beginner-friendly tools.

Browser

HTML forms and CSS pages you click through.

Flask

Python routes receive each request and check the input.

CSV files

patients, appointments and billing are stored as simple files.

Pandas & charts

Data is analysed and drawn as Matplotlib and Seaborn graphs.
